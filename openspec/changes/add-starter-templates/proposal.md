# Change: add-starter-templates

## Why

UI/UX 檢視的 P0 第三項（啟動）：對非技術使用者，空白畫面是最大門檻。
與其給新手一張白紙，不如給幾個一鍵可用的起點——這是提升「第一次就成功」最有效的一步。

## What Changes

- **內建範本**：提供一組預設例行程序範本，一鍵帶入可跑的積木堆疊，使用者可再編輯
- **入口**：
  - 空狀態畫面：從「建立第一個例行程序」改為**範本選擇格**（六選一 + 空白）
  - 非空狀態：FAB 或選單提供「從範本建立」與「空白建立」兩條路
- **範本內容**（皆為現有觸發/動作組合，不新增能力）：
  - **早晨**：定時 08:00 → 顯示通知「早安」＋媒體音量 60%
  - **就寢**：定時 23:00 → 勿擾開＋螢幕亮度 20%＋響鈴靜音
  - **到公司**：進入區域 → 響鈴靜音＋顯示通知「已到公司」
  - **回家**：連上指定 Wi-Fi → 藍牙開＋媒體音量 50%
  - **省電**：電量低於 20% → 勿擾開＋螢幕亮度 20%
  - **空白**：沿用現行從零建立
- 套用範本＝建立一份可編輯的新 routine（帶預設名稱、預設啟用關閉待使用者確認），
  需要位置/SSID 的範本在套用後引導使用者補上參數（區域選點、SSID）

## Non-goals

- 範本市集/雲端範本/分享（純本地內建清單）
- 新增任何觸發或動作能力（範本只是既有能力的預組合）
- 匯入匯出 routine（另議）

## Impact

- 受影響 specs：routine-management（空狀態與建立流程 ADDED 範本）
- 受影響程式碼：新增 templates 定義（純資料，用既有 model 組出 Routine）、
  ui\HomeScreen.kt（空狀態範本格、FAB/選單入口）、套用後導向 EditScreen 讓使用者確認/補參數
- 無新增依賴；versionName 隨 P0 批次（若與 safer-delete 同批發版則共用；此 change 獨立可 archive）
