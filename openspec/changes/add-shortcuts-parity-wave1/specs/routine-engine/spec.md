# routine-engine — 執行服務

## ADDED Requirements

### Requirement: 前景執行服務
由觸發條件（定時、地理圍欄、充電/電量、藍牙、Wi-Fi、系統狀態）啟動的程序執行 SHALL 於短生命週期前景服務中進行：服務啟動後依序執行動作、寫入執行紀錄，完成即自動停止。含長時動作（等待、朗讀、HTTP）的程序不得因廣播接收器時限而中斷或 ANR。手動執行維持於 App 行程內直接執行。

#### Scenario: 長時程序由觸發執行
- **WHEN** 含「等待 30 秒」的程序由定時觸發
- **THEN** 全部動作依序完成、寫入紀錄、服務自動停止，無 ANR 或崩潰

#### Scenario: 服務啟動失敗降級
- **WHEN** 前景服務因系統背景限制無法啟動
- **THEN** 於接收器內同步執行動作但跳過等待類動作，並於紀錄註明降級
