# Change: add-view-and-variable-ux

## Why

使用者回饋兩件事：

1. **首頁只有一種呈現方式**（每張卡片都攤開觸發／動作積木），routine 一多就太長、掃視困難。
   希望能切換成更精簡的呈現。
2. **變數雖然做好了，但多數人看不懂怎麼用、也不直觀**——插入 `{{時間}}` 後看不出「到底會變成什麼」，
   也沒有現成的變數範例可照著改。

（另有 APK 更新問題＝CI 每次用不同的簽章金鑰，已改走固定 release keystore 修掉，非本 change 範圍。）

## What Changes

- **首頁兩種呈現方式（可切換、會記住）**：頂部切換鈕在「清單」與「格狀」之間切換，選擇持久化。
  - **清單**：一列一張，只顯示名稱 + 狀態晶片 + 執行／開關；**不顯示下方的觸發／動作積木**（精簡掃視）。
  - **格狀**：2 欄方塊卡，色塊 + 名稱 + 一行狀態 + 執行／開關（概覽用）。
  - 清單模式維持長按拖曳排序（沿用 v0.17.0）；格狀模式為概覽、不排序（排序回清單模式做）。
- **變數更直觀**：
  - **即時預覽**：含變數的文字欄下方顯示「預覽：…」，用範例值把 `{{時間}}` 等代換成看得懂的樣子
    （例如 `現在 {{時間}}` → 預覽 `現在 21:45`）。純顯示、不影響儲存與執行。
  - **變數範例範本**：範本格新增示範變數的現成 routine（報時分享、通知轉發），
    使用者套用後直接看到變數在真實情境怎麼串起來。

## Non-goals

- 格狀模式的拖曳排序（排序在清單模式做即可，格狀為概覽）
- 跨捷徑／全域變數、控制流程（if/while/for）——屬 v1.0.0，另議
- 變更序列化格式或既有變數語法（預覽只是顯示層）

## Impact

- 受影響 specs：routine-management（首頁呈現方式）、routine-actions（變數欄預覽、變數範本）
- 受影響程式碼：ui/HomeScreen（view mode 切換 + 清單／格狀兩種呈現、偏好持久化）、
  ui/ActionEditor（VariableTextField 預覽）、ui/RoutineTemplates（變數範例範本）、
  engine/Variables（範例值預覽解析，純顯示用）
- 依賴：無新增；versionName 0.18.0 / versionCode 18
