# routine-actions — 分享

## ADDED Requirements

### Requirement: 分享動作
系統 SHALL 支援「分享」動作：把使用者設定的文字（連結或任意文字）透過系統分享選單送出，由使用者當下選擇分享對象或 App。手動執行 / App 在前景時 SHALL 直接跳出分享選單；背景觸發時若系統禁止背景啟動，SHALL 改發可點擊通知，點擊後才跳出分享選單，並於結果誠實註明，不得崩潰。分享文字為空時記為失敗。

#### Scenario: 手動分享連結
- **WHEN** 使用者手動執行含「分享：https://example.com」的例行程序
- **THEN** 跳出系統分享選單，使用者可選擇要分享到哪個 App／給誰

#### Scenario: 背景觸發降級
- **WHEN** 分享動作由背景觸發且系統禁止背景啟動 Activity
- **THEN** 改發可點擊通知，點通知才跳出分享選單，結果註明改以通知呈現

#### Scenario: 空內容
- **WHEN** 分享動作的文字為空
- **THEN** 動作記為失敗，後續動作照常執行
