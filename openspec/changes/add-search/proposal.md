# Change: add-search

## Why

使用者回饋：例行程序與可選的觸發/動作變多後「都找不到」。需要搜尋。
同時首頁卡片排版可以更緊湊、更有條理。

## What Changes

- **首頁搜尋**：清單畫面頂部加搜尋列，依**名稱**（及觸發/動作摘要文字）即時過濾例行程序；
  空字串顯示全部；查無結果顯示「找不到符合的例行程序」空狀態
- **調色盤搜尋**：觸發與動作的調色盤 bottom sheet 頂部加搜尋欄，即時過濾積木；
  分組小標在該組無符合項時隱藏；查無顯示提示
- **首頁排版微調**：卡片與積木間距略收緊、頂部加入搜尋列的整潔安排，讓一屏容納更多、
  更好掃視（不改積木造型/配色，只調密度與版面）

## Non-goals

- 標籤/分類/資料夾（本次只做文字搜尋）
- 搜尋執行紀錄（另議）
- 積木造型、配色改動（維持現況）

## Impact

- 受影響 specs：routine-management（清單搜尋、調色盤搜尋、排版密度）
- 受影響程式碼：ui\HomeScreen.kt（搜尋列 + 過濾 + 空狀態 + 密度）、ui\blocks\BlockPalette.kt（搜尋欄 + 過濾）、
  可能 ui\RoutineViewModel.kt（查詢狀態）
- 無新增依賴；versionName 0.16.0 / versionCode 16
