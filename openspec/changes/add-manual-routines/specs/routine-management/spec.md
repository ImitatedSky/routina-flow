# routine-management — 手動例行程序的卡片

## ADDED Requirements

### Requirement: 手動例行程序的卡片呈現
手動執行的例行程序 SHALL 於首頁卡片隱藏啟用開關（無可排程項目），並以明確的 ▶ 執行為主要操作；狀態晶片 SHALL 不顯示「下次執行」，改以中性「手動」標記呈現，若有執行紀錄則顯示上次結果。具有自動觸發的例行程序卡片維持原有的開關與狀態晶片。

#### Scenario: 手動卡片無開關
- **WHEN** 一個手動例行程序顯示於清單
- **THEN** 卡片不顯示啟用開關，顯示「手動」標記與 ▶ 執行

#### Scenario: 手動卡片可執行
- **WHEN** 使用者於手動例行程序卡片點 ▶
- **THEN** 依序執行其動作並寫入紀錄

#### Scenario: 自動卡片維持原樣
- **WHEN** 一個具定時觸發的例行程序顯示於清單
- **THEN** 卡片維持啟用開關與「下次執行」狀態晶片
