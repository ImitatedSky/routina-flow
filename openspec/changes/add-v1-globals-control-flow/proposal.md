# 全域變數與控制流程（v1.0.0）

## 目的

把 Routina 從「觸發 → 一串動作照順序跑完」升級成能**跨程序共享狀態**並**依條件分支／重複**的自動化：

1. **全域變數**（跨程序、可持久化）：一個程序寫入的值，另一個程序讀得到，且 App 重啟後仍在。
2. **控制流程**：`如果 / 否則如果 / 否則`、`一直重複…當`（while）、`重複 N 次`（for）。

這是 [add-variables](../add-variables/) 明確列為「後續大波」的延伸；當時把控制流程與跨程序變數都保留給 v1.0.0。

## 範圍分層（每層可獨立運作、獨立發版）

- **第 1 層 全域變數** — ✅ 本次已實作。新增「設定全域變數」動作、`{{全域:名稱}}` 解析、`global_vars.json` 持久化、全域變數管理畫面。不動執行引擎。
- **第 2 層 條件** — 待實作。`如果 / 否則如果 / 否則`。把扁平 `mapIndexed` 執行改為游標式直譯器，加入條件求值。
- **第 3 層 迴圈** — 待實作。`while` 與 `重複 N 次`，建在第 2 層的直譯器上，含防無限迴圈上限。

## 非目標

- **巢狀資料 / 陣列型變數 / for-each 逐項**：全域變數仍是「名稱→字串」。for 先做「重複 N 次」，逐項迭代（for each item）留待後續。
- **型別系統**：變數值仍一律是字串，比較時視內容自動當數字或字串處理（見 design.md）。
- **拖曳時自動維持配對區塊**：第一版採「直譯器對不成對的標記保持穩健（不崩潰）」而非複雜的配對拖曳邏輯（見 design.md）。

## 相容性

新增的 Action 子型別都是**附加**的：既有 `routines.json` 不含這些型別，載入完全不受影響（sealed 多型 + 全欄位有預設值）。風險只在「舊版 App 讀到含新型別的資料」（降版），個人側載情境可接受。
