# routine-management（例行程序管理）— Scratch 積木化 UI

## MODIFIED Requirements

### Requirement: 清單顯示與顏色區隔
清單畫面 SHALL 以卡片列出所有例行程序，每張卡片內以**縮小版唯讀彩色積木堆疊**呈現內容：觸發條件與動作各為一塊圓角色塊（顏色依**功能分組色系**——同組使用同一色相、組內以相近色階區分，文字說明 + 白色參數欄，無拼圖造型），並顯示名稱與啟用開關。

#### Scenario: 檢視清單
- **WHEN** 使用者開啟 App
- **THEN** 每張卡片顯示名稱、觸發積木＋最多 3 塊動作積木的堆疊預覽（超過部分以「還有 N 個動作」積木表示）、啟用開關與立即執行按鈕

#### Scenario: 停用狀態視覺
- **WHEN** 例行程序為停用狀態
- **THEN** 其積木堆疊以 40% 透明度呈現，開關為關

#### Scenario: 空清單
- **WHEN** 尚無任何例行程序
- **THEN** 顯示空狀態說明文字與建立引導

## ADDED Requirements

### Requirement: 積木編輯器
編輯畫面 SHALL 以積木編輯器呈現：點狀網格畫布上有一塊觸發積木、其下垂直堆疊動作積木、末端為虛線幽靈積木「＋ 加入動作」；所有積木為簡單圓角色塊（無拼圖凹凸），顏色依功能分組色系（同組同色相、組內相近色階），以文字說明為主要辨識，參數以內嵌白色圓角參數欄顯示，點選即可編輯。

#### Scenario: 更換觸發類型
- **WHEN** 使用者點擊觸發積木本體
- **THEN** 顯示含所有觸發類型彩色積木的調色盤選單，選擇後更換觸發類型並保留可共用的參數

#### Scenario: 加入動作
- **WHEN** 使用者點擊幽靈積木
- **THEN** 顯示含所有動作類型彩色動作積木的調色盤選單，選擇後動作積木卡接到堆疊末端並開啟其參數編輯

#### Scenario: 編輯參數
- **WHEN** 使用者點擊積木上的參數欄或動作積木本體
- **THEN** 開啟對應的參數編輯器（時間選擇、星期複選、滑桿、文字輸入等），完成後參數欄即時更新

#### Scenario: 調整動作順序與移除
- **WHEN** 使用者點擊動作積木上的上移／下移／移除圖示
- **THEN** 積木堆疊即時重排或移除該積木，執行順序隨之改變
