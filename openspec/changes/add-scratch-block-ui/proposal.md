# Change: add-scratch-block-ui

## Why

使用者實機使用後的回饋：希望介面排版像 **Scratch** 一樣——例行程序以「積木堆疊」呈現，
觸發條件在頂端、動作是一塊塊往下接的彩色積木。
現有的顏色系統（觸發/動作各有專屬色）與 Scratch 的分類色概念天然吻合，
積木化能讓「觸發 → 依序執行動作」的心智模型一眼可讀，也更有趣味性。

## What Changes

**純 UI 層改版，資料模型、執行引擎、儲存格式完全不動。**

- 新增積木元件（純 Compose，零新依賴）：
  - 觸發積木＝圓角色塊，用觸發類型色
  - 動作積木＝圓角色塊，用動作類型色，垂直堆疊
  - 積木內嵌白色圓角參數欄（時間、星期、門檻、音量……）
  - 註：初版做了 Scratch 的帽子圓弧與卡榫，實測後（見 design.md 修訂）簡化為圓角色塊
- **編輯畫面**改為積木編輯器：點狀網格背景畫布、觸發積木 + 動作積木堆疊、
  虛線幽靈積木「＋ 加入動作」、積木調色盤（palette）選單、動作可上下移動
- **清單畫面**：卡片內以縮小版唯讀積木堆疊預覽取代文字摘要 + chip
- 執行紀錄畫面不變

## Non-goals（本次不做）

- 自由拖放定位、拖曳吸附動畫（Scratch 的 drag & drop）——用點選調色盤 + 上下移動鈕替代
- C 型積木（迴圈/條件包夾）、變數、橫向積木——引擎沒有這些概念
- 積木水平縮放/工作區縮放手勢

## Impact

- 受影響 specs：routine-management（清單顯示、新增積木編輯器需求）
- 受影響程式碼：僅 ui/ 目錄（HomeScreen、EditScreen、theme、新增 blocks/ 元件）；
  model/、data/、engine/ 零更動
