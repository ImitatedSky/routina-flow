# Design: add-scratch-block-ui

> **2026-08-22 修訂（使用者實測回饋）**：拿掉 Scratch 的拼圖卡榫與帽子圓弧——
> 對不懂程式的人反而更難懂。改為**簡單圓角色塊**：顏色、白色參數欄、垂直堆疊、
> 調色盤概念全部保留，只簡化形狀。

## 積木視覺語言（Compose，零新依賴）

圓角矩形色塊 + 同色系深 25% 的 1.5dp 邊框，不做任何拼圖造型。

### 幾何規格

| 參數 | 值 |
|------|----|
| 形狀 | RoundedCornerShape 12dp（所有積木一致，無凹凸、無圓弧頂） |
| 積木最小高度 | 48dp（編輯器）/ 34dp（清單縮小版） |
| 堆疊間距 | Column 垂直間距 6dp（不重疊、不需 zIndex） |

### 積木種類

- **觸發積木**：圓角色塊，色＝觸發類型色（定時藍 #1E88E5、開始充電橘 #FB8C00、停止充電橘紅 #E53935、電量綠 #43A047、進入區域青藍 #00ACC1、離開區域深紫 #5E35B1），文字直接說明（「當 … 到 …」）
- **動作積木**：圓角色塊，色＝動作類型色（通知紫 #8E24AA、開 App 青 #00897B、開網址靛 #3949AB、音量粉 #D81B60、響鈴棕 #6D4C41、藍牙深藍 #1565C0）
- **幽靈積木**：虛線邊框、透明底、置中「＋ 加入動作」，同圓角矩形

### 積木內容

白色粗體標籤文字 + **白色圓角參數欄**（白底 90%、深色文字，如 Scratch 的輸入欄）：
- 定時：`每天/週一三五` `08:00` 兩個參數欄
- 電量：`20%`；音量：`60%`；通知：標題參數欄；開 App：App 名稱；網址：網址（過長截斷）

## 畫面設計

### EditScreen（積木編輯器）

```
┌ TopBar：返回 / 標題 / 刪除 ─────────────┐
│ 名稱 TextField                          │
│ ┌─ 積木畫布（點狀網格背景、可捲動）──┐ │
│ │ ╭──────────────────╮ ← 觸發積木      │ │
│ │ │ 當 每天 08:00     │                │ │
│ │ ╰──────────────────╯                 │ │
│ │ ╭──────────────────╮ ← 動作積木      │ │
│ │ │ 顯示通知 [標題] ↑↓✕│               │ │
│ │ ╰──────────────────╯                 │ │
│ │ ┆ ＋ 加入動作        ┆ ← 幽靈積木    │ │
│ └──────────────────────────────────────┘ │
│ [儲存] （名稱空或無動作時 disabled）     │
└──────────────────────────────────────────┘
```

- 點**觸發積木本體** → 觸發調色盤 bottom sheet（各類型積木可選，換類型保留可共用參數）
- 點觸發積木的**參數欄** → 對應編輯器（沿用現有 TimePicker 對話框、星期 FlowRow、電量滑桿）
- 點**動作積木本體** → 沿用現有 ActionEditDialog 編輯參數
- 動作積木右側白色半透明小圖示：↑ ↓（換順序）、✕（移除）
- 點**幽靈積木** → 動作調色盤 bottom sheet（5 塊彩色積木預覽 + 名稱）
- 畫布背景：`drawBehind` 畫點陣（間距 20dp、1dp 半徑、outline 12% alpha），Scratch 編輯區質感
- 草稿仍用 rememberSaveable + Json Saver（沿用既有機制，不得回退）

### HomeScreen（清單）

- 卡片內改放**縮小版唯讀積木堆疊**（compact：高 34dp、字 12sp、圓角 10dp、參數欄縮小）：
  觸發積木 + 最多 3 塊動作積木，超過顯示末塊「⋯還有 N 個動作」灰積木
- 移除原 4dp 左色條與文字摘要列（顏色資訊已由積木承載）
- 卡片底列維持：啟用 Switch + 立即執行鈕；點卡片進編輯
- 停用的 routine：積木堆疊 40% alpha
- 空狀態、權限引導卡、Snackbar 行為不變

### 深淺色模式

積木顏色兩種模式共用（飽和色在深色底也成立）；畫布點陣與卡片底色跟隨 M3 色盤；
參數欄固定白底深字（Scratch 慣例），深色模式下對比足夠。

## 實作結構

```
ui/blocks/
├── RoutineBlocks.kt  # BlockMetrics 幾何常數 / BlockSurface / TriggerBlock / ActionBlock /
│                     # GhostBlock / MoreActionsBlock / ParamField / BlockStack
└── BlockPalette.kt   # 觸發調色盤 sheet / 動作調色盤 sheet
```

形狀直接用 `RoundedCornerShape`，不需要自繪 path；幽靈積木的虛線外框以 `drawBehind` +
`drawRoundRect(style = Stroke(pathEffect = dashPathEffect))` 畫出。

HomeScreen / EditScreen 改用上述元件；theme 色表不變。
